# Social automation — Twitter, Instagram, TikTok

This is the setup checklist for getting the auto-post endpoints working
end-to-end. Twitter is already live; Instagram + TikTok need one-time
auth steps from you because each platform requires a per-user OAuth flow
that I can't automate.

---

## ✅ Twitter (LIVE)

Already wired up. Endpoints:

- `POST /api/admin/post-tonight-acca` — one-shot tonight's acca tweet
- `POST /api/admin/post-kickoff-alerts` — minute-1 kickoff alerts
- `POST /api/admin/post-tweets` — generic tweet poster (single or thread)

GitHub Actions workflow `.github/workflows/kickoff-alerts.yml` polls
the kickoff endpoint every 5 min during football hours.

Required env vars (already set in Vercel):

```
TWITTER_API_KEY
TWITTER_API_SECRET
TWITTER_ACCESS_TOKEN
TWITTER_ACCESS_SECRET
CRON_SECRET
```

GitHub repo secret: `CRON_SECRET` (same value, set under
Settings → Secrets and variables → Actions).

## 📷 Instagram (endpoint built, needs your OAuth)

Endpoint: `POST /api/admin/post-instagram`

### One-time setup (~30 min)

1. **Convert your IG account** (if not already) to **Business** or
   **Creator** — Settings → Account → Switch account type.
2. **Connect IG to a Facebook Page** — Settings → Business → Instagram.
   Create a Page if you don't have one.
3. **Create a Meta App** at https://developers.facebook.com/apps:
   - Type: **Business**
   - Add product: **Instagram Graph API**
4. **Generate a Page Access Token** in Graph API Explorer:
   - https://developers.facebook.com/tools/explorer
   - User token → switch to your Page token
   - Required scopes:
     - `instagram_basic`
     - `instagram_content_publish`
     - `pages_show_list`
     - `pages_read_engagement`
5. **Exchange for a long-lived token** (60 days):
   ```
   GET https://graph.facebook.com/v18.0/oauth/access_token
     ?grant_type=fb_exchange_token
     &client_id={app-id}
     &client_secret={app-secret}
     &fb_exchange_token={short-token}
   ```
6. **Get the IG Business Account ID:**
   ```
   GET /me/accounts?access_token={page-token}     → page id
   GET /{page-id}?fields=instagram_business_account&access_token={page-token}
   ```
7. **Add to Vercel env:**
   ```
   INSTAGRAM_ACCESS_TOKEN=<long-lived token>
   INSTAGRAM_USER_ID=<numeric IG account id>
   ```

### Test it

```bash
# Dry run (preview caption + image URL, no post)
curl -X POST https://www.matchmindcom.com/api/admin/post-instagram \
  -H "Authorization: Bearer $CRON_SECRET" \
  -H "Content-Type: application/json" \
  -d '{"dryRun": true}'

# Real post
curl -X POST https://www.matchmindcom.com/api/admin/post-instagram \
  -H "Authorization: Bearer $CRON_SECRET" \
  -H "Content-Type: application/json" \
  -d '{}'
```

The image is auto-generated by `/api/og/acca` (Vercel OG, square 1080x1080).
The caption is the same acca tweet body + IG-friendly hashtags.

### Long-lived token refresh

Long-lived IG tokens expire every 60 days. Refresh before expiry:

```
GET https://graph.facebook.com/v18.0/oauth/access_token
  ?grant_type=fb_exchange_token
  &client_id={app-id}
  &client_secret={app-secret}
  &fb_exchange_token={current-long-token}
```

(Could be automated via a monthly Vercel cron — out of scope for now.)

## 🎵 TikTok (endpoint built, needs your OAuth + video pipeline)

Endpoint: `POST /api/admin/post-tiktok`

### One-time setup (~1-2 weeks because of TikTok's app review)

1. **Apply at https://developers.tiktok.com** with the @MatchMind_AI
   account.
2. **Create an app**, request the `video.publish` scope. **Note: app
   review can take 5-10 business days.** TikTok rejects vague use cases —
   describe the use case as "automated daily posting of pre-recorded
   short-form acca picks for the @MatchMind_AI account only".
3. **Run the OAuth redirect flow** once for your @MatchMind_AI account
   to get an access token. The flow is:
   ```
   https://www.tiktok.com/v2/auth/authorize/
     ?client_key={your-client-key}
     &response_type=code
     &scope=video.publish
     &redirect_uri={your-redirect}
     &state={random}
   ```
   Then exchange the returned `code` for an access token via:
   ```
   POST https://open.tiktokapis.com/v2/oauth/token/
   ```
4. **Add to Vercel env:**
   ```
   TIKTOK_ACCESS_TOKEN=<access token>
   ```
   Refresh tokens are valid 365 days; access tokens are valid 24h.
   You'll need to run a refresh-token cron eventually — out of scope
   for now.

### Video requirement

TikTok **does not allow text-only posts via API**. Every post needs a
video. For the acca cards, you have a few options:

**Option A (simplest, manual):** Pre-record a 15-30s vertical (1080x1920)
clip showing the acca picks once a day. Upload to Supabase Storage or
Cloudinary, pass the public URL.

**Option B (semi-automated):** Use Remotion (`npm i remotion @remotion/cli`)
to render a video from the same data the OG image uses. Render → upload →
call this endpoint. ~3-4 hours of dev work.

**Option C (skip TikTok native):** Use a 3rd-party cross-poster like
Buffer or Later. They convert your tweets to TikTok stories
automatically. Free tier covers low volume.

### Test it (dry run, doesn't need a video)

```bash
curl -X POST https://www.matchmindcom.com/api/admin/post-tiktok \
  -H "Authorization: Bearer $CRON_SECRET" \
  -H "Content-Type: application/json" \
  -d '{"dryRun": true}'
```

### Real post (requires videoUrl)

```bash
curl -X POST https://www.matchmindcom.com/api/admin/post-tiktok \
  -H "Authorization: Bearer $CRON_SECRET" \
  -H "Content-Type: application/json" \
  -d '{"videoUrl": "https://your-cdn/acca-2026-04-30.mp4"}'
```

## Pragmatic recommendation

Twitter is your highest-value channel and it's fully automated. For
Instagram + TikTok, the realistic ROI today is:

- **Instagram**: Worth the 30 min setup. Once tokens are in, a daily
  cron can post the acca card alongside Twitter. Free, native API.

- **TikTok**: Skip the native API for now. The 1-2 week app review +
  video pipeline isn't worth it until you have steady IG growth.
  When you're ready, **Buffer** ($6/mo) or **Later** (free tier)
  cross-post tweets to TikTok automatically with no code.
